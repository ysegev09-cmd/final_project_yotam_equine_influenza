# final_project_yotam_equine_influenza
הפונקציה עובדת על פרמטרים :
n שהוא הכמות הכוללת של החמורים שאנו עובדים איתם יש להכניס כמספר שלם
start sick שהוא אחוז החמורים החולים הראשונים יש להכניס כמספר שלם,
gama שזה קצב ההחלמה יש להכניס כשבר עשרוני,
beta שזה קצב הדבקה אשר גם אותו יש להכניס כשבר עשרוני,
יש גם לשנות את המספר בלולאה לשינוי כמות הימים וההרצות,
אלו הפרמטרים שיש לשנות לשם העבודה,
ויש לשנות ישר את פרמטרים אלו בתצוגתן.
ישנם גם פרמטרים :
S כמות החמורים שעוד לא חלו,
i כמה חמורים נדבקו באותו היום ,  
I_total כמות החולים הכללית הנוכחית,
r כמה החלימו באותה  יום,
r_total כמה החלימו עד עכשיו,
i_max אשר זה כמות החולים היומית הגדולה ביותר,
וday_max היום של כמות החולים היומית הגדולה ביותר.
יש לקרוא את התוצאות בקובץ situ_update שם מודפסות התוצאות והשינויים במדדים אשר הם הפרמטאים.
בקובץ יש שתי טבלאות :
טבלה ראשונה היא מציגה את השינוי היומי ואת מהלך המחלה,וטבלה שנייה מראה את היקף המחלה (%ב),היום של כמות החולים הגדולה ביותר ,כמות החולים הגדולה ביותר,קצב ההדבקה, קצב ההחלמה, כמות חולים התחלתית,כמות חמורים כוללת.
