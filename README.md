הפונקציה עובדת על פרמטרים :
n שהוא הכמות הכוללת של החמורים שאנו עובדים איתם יש להכניס כמספר שלם
start sick שהוא אחוז החמורים החולים הראשונים יש להכניס כמספר שלם
gama שזה קצב ההחלמה יש להכניס כשבר עשרוני
beta שזה קצב הדבקה אשר גם אותו יש להכניס כשבר עשרוני
יש גם לשנות את המספר בלולאה לשינוי כמות הימים וההרצות
אלו הפרמטרים שיש לשנות לשם העבודה 
יש לשנות ישר את פרמטרים אלו בתצוגתן
ישנם גם פרמטרים :
S כמות החמורים שעוד לא חלו
i כמה חמורים נדבקו באותו היום  שזה הרצה
I_total כמות החולים הכללית הנוכחית
r כמה החלימו באותה הרצה \יום
r_total כמה החלימו עד עכשיו
